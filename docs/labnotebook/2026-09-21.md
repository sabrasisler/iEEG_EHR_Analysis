## 10:25-11:05 — the delta/theta domain-fit failure is OPTIMIZER INSTABILITY, not misspecification

**Ran:** a 2x2 on the diagnosis domain model — {90-day, ever} x {with, without
the parcel-nested random slope}. Slurm 44501830, 44501831, 44509860, 44510830,
~30 min each on `ckeller1`. New flag `--drop-parcel-term` (`5202550`), which
tags its own `noparcel` run directory.

**Why:** delta and theta in the 90-day run carried a non-positive-definite
Hessian after an lbfgs retry, with `var_subj_slope` 300-1100x the four healthy
bands (0.073 / 0.050 against 6.4e-5 to 2.0e-4) and `pain_x_dx` SEs of 0.081 /
0.068 against 0.0035-0.0060. `subj_parcel_slope` is the smallest component in
every band (ratios to residual 1.6e-3 to 4.3e-2 against `BOUNDARY_TOL` 1e-3),
so a flat likelihood direction there was the hypothesis.

**Saw — the hypothesis is WRONG, and the experiment says what is actually going
on.** Dropping the parcel term does not fix the problem; it MOVES it.

| band | 90d WITH parcel | 90d NO parcel |
|---|---|---|
| delta | non-PD, SE 0.081 | **fixed**, SE 0.0071 |
| theta | non-PD, SE 0.068 | **fixed**, SE 0.0055 |
| alpha | fine, SE 0.0060 | **non-PD**, SE 0.0096 |
| gamma | fine, SE 0.0044 | **non-PD**, SE 0.0092 |
| beta / high_gamma | fine | fine |

Four healthy bands either way — a different four. And the label window alone
does the same thing: delta is broken at 90 days and FIXED under `ever` with the
parcel term still in, its `var_subj_slope` falling 0.0735 -> 0.000415 (177x) on
IDENTICAL data. Only the `dx_state` column changed.

So `var_subj_slope` genuinely is ~1e-4. Whenever the optimiser misses that
basin it settles on a spurious 0.05-0.07 with a non-invertible Hessian, and
WHICH band that happens to is arbitrary — any perturbation of the design (the
label window, dropping a variance component) reshuffles it. This is the same
failure already logged for the beta row of the opioid-exclusion run
(2026-09-18), so it is now three independent sightings of one pathology.

**Two things that rule out the obvious alternative readings.** It is NOT
pseudo-replication from dropping the parcel term: over the 20 well-conditioned
cells the betas barely move (Pearson r 0.979 for `pain`, 0.893 for
`pain_x_dx`) and the per-contrast SEs go UP, not down — median ratio 1.085 and
1.110. And it is not real low-frequency heterogeneity, because delta's large
variance evaporates under a relabelling that cannot touch the random effects.

**The no-parcel omnibus is not trustworthy and must not be quoted.** With the
parcel term dropped, `p_omnibus_pain` for beta goes 3.89e-06 -> 8.37e-20 and
`p_omnibus_pain_x_dx` 0.134 -> 9.58e-08, while the marginal SEs rose 8%. The
joint Wald inverts the contrast block's covariance, so it is far more sensitive
to a degraded covariance estimate than any single SE is; in the ever/no-parcel
run alpha reports NOT CONVERGED outright and `pain_x_dx` comes back at 4.46e-20
for beta and 3.21e-10 for gamma. Those are not results.

**Conclusion: KEEP the parcel term. The fix is optimisation, not
specification** — warm-start the three-way from the converged pain-only fit's
parameters (`mm.fit_cell` already takes `start_params`, and the permutation
path already warm-starts for exactly this reason), or fit from several starts
and keep the best likelihood. Until then, exclude any band whose warnings
contain 'not positive definite' rather than reading its interval.
