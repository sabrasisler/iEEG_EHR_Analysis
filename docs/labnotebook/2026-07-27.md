**Saw / decided:**

- `kickoff_plan.md` was doing four jobs at once (phases, near-term actions, repo
  org, IO conventions). The phases and next-actions moved out; repo-org and IO
  conventions stayed, because those are reference material, not control surface.
- Went with a **flag-plus-grep** scheme for "has this run been written up yet":
  `log_analysis()` writes `[ ]`, `/lognote` flips it to `[x]`, but `/lognote` ALSO
  greps `docs/labnotebook/*.md` for the output path. The grep is the truth and the
  flag is a cache — otherwise a notebook entry written by hand would be invisible
  to the very command meant to find it.
- `log_analysis()` swallows all its own exceptions. Deliberate: an index append
  failing must not take down a six-hour array job. Failure prints a warning that
  names the manual escape hatch.
- Dedupe key is (output_path, git_hash), which makes the helper safe to call from
  every task of a Slurm array — all tasks share the run dir and commit, so a
  60-task array collapses to the one line it should be.

**Broken / worked around:**

- Worktree isolation was unavailable: Sherlock's system git is 1.8.3.1, which has
  no `git worktree` at all, and the tooling calls `git -C` (added in 1.8.5). A
  newer git *does* exist as a module (`ml system git` → 2.45.1) and was enough to
  create the worktree by hand. Worth knowing for any future tooling that assumes a
  modern git on the login node.
- **Found while testing: `git_provenance()` silently degrades to `no-git` inside a
  git worktree on a compute node.** Cause is the same old git — a worktree's
  `.git` is a *file* pointing elsewhere, and 1.8.3.1 predates that. Verified both
  ways on `-p dev`: worktree → `available=False`; main checkout → `available=True`,
  commit `0591ac6`. Pre-existing in `io/provenance.py`, not new, and harmless while
  all real runs launch from the main checkout — but it means a definitive run
  launched from a worktree would record no commit at all. (→ scratchpad)
- `phi_manifest.py` is referenced by the spec but lives outside this repo (PHI
  side). Confirmed with Sabra: nothing reachable on Oak/Sherlock contains PHI, so
  the prose discipline in these files is a convention, not a gap.
